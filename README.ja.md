# ar-handtrack-torus

three.js を使用した AR handbutton からフォークされた AR handtrack です。

## デモ
https://code4fukui.github.io/ar-handtrack-torus/

## 機能
- ARトーラス
- La Tempo のARホットサンド
- SLIM The Coffee Resort のARケーキ
- Kitatei のAR海鮮丼

## 使い方
ウェブサイトにアクセスし、カメラへのアクセスを許可してAR機能を体験してください。
